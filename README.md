# SAT Vocab Practice
A calm, no-account practice area for the 384 words in [PrepScholar's SAT vocabulary list](https://blog.prepscholar.com/sat-vocabulary-words): 39 units of up to 10 words, a cumulative review (Unit 1 through the current unit) after every two units, six 60-word Big Tests, and a 384-word Final Test; a Daily Review tab (each Pacific day, all previously started words must be answered 100% on the first try before the path continues); each step unlocks after 100% first-try accuracy on the previous one, flashcards, multiple choice, typed recall, spaced reviews (1, 3, 7, 14, 30 days), weak-word practice, and backup/restore. Progress is stored in your browser's localStorage.

Definitions are mostly from [Open English WordNet 2024](https://en-word.net/) (CC BY 4.0). Not affiliated with College Board. Run tests with `node test.js`.
